## Quick Start

1. Create your bot via [@BotFather](https://t.me/botfather)
2. Fork/copy this template repository
3. Set up the `production` environment with required secrets
4. Enable Actions in your fork
5. Change the cron minute in `.github/workflows/run.yml`
6. Run manually to verify
